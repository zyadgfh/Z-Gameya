# تطبيق «الجمعية» (Gameya)

تطبيق جمعية ادخار دورية: قسط ثابت لكل عضو، ويقبض عضو واحد في كل دورة.
**التطبيق للتتبع والتنظيم فقط — لا يمر مال عبره إطلاقاً.** الدفع خارجي (كاش، فودافون كاش، إنستا باي).

## التقنية (Phase 0)
- **تطبيق هجين:** Expo (React Native + TypeScript) — كود واحد لأندرويد وآيفون
- **قاعدة البيانات والمصادقة:** Supabase (Postgres + Auth برقم الموبايل OTP + Storage للإيصالات)
- **الواجهة:** عربية RTL، تصميم بأسلوب Apple HIG
- **رصد الأخطاء:** Sentry (اختياري — ضع DSN في `.env`)
- **الاختبارات:** Jest — المنطق المالي مغطى منذ البداية

## التشغيل
```bash
npm install
cp .env.example .env   # املأ قيم Supabase
npm start              # ثم اختر Android / iOS / Web
npm test               # اختبارات المنطق المالي
```

## هيكل المشروع
```
app/                  شاشات Expo Router (دخول، تبويبات: جمعياتي/إنشاء/إشعارات/حسابي)
src/lib/finance.ts    المنطق المالي النقي (مبلغ القبض، الرسوم، الجدول، القرعة، التأخير)
src/lib/supabase.ts   عميل Supabase + تخزين آمن للجلسة
src/lib/auth.ts       تسجيل الدخول برقم الموبايل (OTP)
supabase/migrations/  مخطط قاعدة البيانات + RLS + دالة حجز الدور
__tests__/            اختبارات وحدة (17 اختباراً)
```

## أمثلة محسوبة
- مبلغ القبض = القسط × عدد الأعضاء → 500 × 12 = 6,000 جنيه
- الرسوم = مبلغ القبض × النسبة → 6,000 × 0.5% = 30 جنيهاً
- عدد الدورات = عدد الأعضاء → 12 عضواً شهرياً = 12 شهراً
